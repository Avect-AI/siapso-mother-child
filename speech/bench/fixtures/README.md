# Bench fixture

`fleurs-wo_sn-test-9405789794868564555.wav` is one Wolof utterance of the FLEURS dataset, used by `speech/bench/bench.spec.ts` to time the speech model. It is the only audio file in the repository.

- Source: FLEURS (Conneau et al., 2022, "FLEURS: Few-shot Learning Evaluation of Universal Representations of Speech"), Hugging Face dataset `google/fleurs`, revision `70bb2e84b976b7e960aa89f1c648e09c59f894dd`, file `data/wo_sn/audio/test.tar.gz`, member `9405789794868564555.wav`.
- Licence: Creative Commons Attribution 4.0 International (CC BY 4.0), https://creativecommons.org/licenses/by/4.0/.
- Transcription (FLEURS `transcription` column): "great pyramid bi ci giza dong mo taxaw batay".
- Changes: silence removed at both ends (kept 0.79 s to 4.09 s of the original 5.28 s, with 150 ms of margin around the speech), written as 16-bit PCM, 16 kHz, mono (3.30 s). The speech itself is unchanged.
