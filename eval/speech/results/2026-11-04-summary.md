## Run

- Packs: `whisper-small-wolof-q8`, `whisper-base-fr-q8`, the 8-bit ONNX graphs of the voice packs (`speech/convert/`), read from `out`.
- Decoding: greedy, at most 96 new tokens, the decoder prompt recorded in each pack (Wolof: `<|startoftranscript|>` alone; French: `<|startoftranscript|><|fr|><|transcribe|><|notimestamps|>`), as the browser worker.
- Runtime: Transformers.js 4.3.1 in Node v26.13.0 with onnxruntime-node (CPU), win32 x64, AMD Ryzen 5 8640HS w/ Radeon 760M Graphics, 12 logical cores. The browser uses ONNX Runtime Web (WebAssembly): same graphs, same decoding, but another ONNX Runtime build, so a word or two may differ.
- Times are from this machine, not from a phone: see `docs/voice.md` for phone timings.
- Wolof honesty note: the training data of the Wolof fine-tune lists FLEURS `wo_sn` among its sources (splits not stated), so the FLEURS Wolof figure may be optimistic. Only recordings never used in training measure the model fairly.
- Sample size: 100 sentences per language is small; read the figures as indications, not as precise rates. Wolof spelling varies, and each variant counts as an error.
