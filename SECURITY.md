# Security

Report a vulnerability, an exposed secret or personal data privately, with GitHub's private vulnerability reporting: the Security tab of this repository, then "Report a vulnerability". Never in a public issue or pull request. The maintainers acknowledge a report as soon as it is read.

A medical safety report (a rule, a message or a registry entry that seems wrong or harmful) may go through the same private channel or a public issue; it follows the 24-hour withdrawal of [GOVERNANCE.md](GOVERNANCE.md).

Dependabot alerts and security updates are enabled on the repository. Secrets, keys and personal data must never be committed: see `.gitignore` and `CLAUDE.md`.
