The model repositories declare Apache-2.0 on their cards, carry no licence file and name no copyright holder. The copyright line the pack cites, "Copyright (c) 2016 PaddlePaddle Authors", comes from the `LICENSE` of the PaddleOCR GitHub project, not from the model repositories. The pack ships that `LICENSE` as it is at the pinned commit (`licenses/paddleocr-LICENSE.txt`), with `NOTICE.md`; there is no PaddleOCR `NOTICE` to carry (Apache License 2.0, section 4(d)). The commit is the one of the release tag nearest the models' revisions (2026-05-26 and 2026-06-10); `pnpm ocr:install-local` checks the text by size and SHA-256.

## Data

No data is used to build or measure the pack beyond synthetic prescriptions made by the tests and the bench (fake names, no real prescription), and the scanned page fixtures of `ocr/test/fixtures/` (the same kind of synthetic page, made with Pillow). No training is done.
