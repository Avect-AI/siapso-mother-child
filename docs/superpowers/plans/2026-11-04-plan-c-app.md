# Plan C: installable offline app

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The complete keyboard journey of SIAPSO Mother-Child, installable and working in airplane mode, in French and English, in woman mode and accompanied mode.

**Architecture:** `app/` is a Vite React PWA. It loads the knowledge pack fragments from `/pack/` (precached by the service worker) into IndexedDB, builds the resolver index, and calls `evaluate` from `@siapso/engine` with a context built from the profile and the current check. State lives in a React context backed by IndexedDB. Routing is hash based. Spec: `docs/superpowers/specs/2026-11-03-implementation-design.md` sections 2, 5, 7, 10. Visual system: `DESIGN.md`, `app/src/styles/tokens.css`, `app/src/ui/*`.

**Tech Stack:** React 19.3.1, Vite 8.3.4, `vite-plugin-pwa@2.0.0` (with `workbox-window@7.4.1`), `idb@8.0.4`, `wouter@3.13.0`, Vitest 5.0.5 with Testing Library and `fake-indexeddb@6.2.6`, Playwright 1.64.1 with `@axe-core/playwright@4.14.0`.
